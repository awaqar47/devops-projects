# Terraform AWS S3 Project

This project demonstrates how to use Terraform to provision AWS resources including:

- AWS S3 Bucket creation
- Uploading files to S3
- Creating custom IAM Policies
- Attaching IAM Policy to an existing IAM User

---

## Technologies Used

- Terraform
- AWS
- S3 Bucket
- IAM Policy & User Attachment
